# Agent knowledge folders

One folder per subagent in `.claude/agents/`. Each `README.md` explains what that agent stores.
Knowledge folders hold durable lessons, evidence and role-specific checklists — not deliverables
(those live in `docs/` and source folders) and never secrets or real-world confidential data.
